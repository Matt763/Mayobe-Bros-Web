`assets/posts/necta-{csee,acsee,psle}-results-{2025,2024,2023}.webp` (1400 x 788, WebP q90): drawn in code by `scripts/tools/results-post-art.html`. Made at the owner's request; every cover contains:
- **The NECTA logo**: `scripts/tools/necta-logo.png`, NECTA's own file `https://necta.go.tz/img/logo.png` (downloaded 2026-11-09, 100 x 100 px, enlarged with ffmpeg lanczos to 300 px). It belongs to the National Examinations Council of Tanzania; it is shown only to say whose results the post is about, never as the site's own mark, and each post's credit line says so. This is an exception to the "no real logo" rule in CLAUDE.md, made at the owner's request.
- **The flag of Tanzania**: not a file; drawn from the published geometry (72 x 48, green and blue triangles #1EB53A and #00A3DD, black band with yellow #FCD116 edges, strokes 13 and 19) and made to wave in code. The flag is a national symbol, not a licensed picture.
- **Words and shapes**: original, drawn in code. System fonts (Lato, Liberation, DejaVu, Noto) only while drawing; the WebP files contain no font files. No photographs.
