Maybe you have looked at a screen full of code and thought, "That is for other people." It is not. Programming is a skill that you learn one small step at a time, and some of the best places to learn it cost nothing. This post shows four of them and a plan for your first month.

## The short answer

Start with one free course and stay with it. For most beginners, the easiest first step is to learn how web pages are built (HTML, CSS and JavaScript) in your browser, then add one language such as Python, and then make small projects of your own.

- freeCodeCamp lets you learn step by step in the browser, in a code editor or in a mobile app.
- Harvard's CS50x is a free university course that needs no earlier programming.
- MDN has a clear learning path for HTML, CSS and JavaScript.
- python.org has the official Python downloads and beginner pages.
- Learning to code is a skill. It is not a promise of a job or of money.

## What do you need to start?

Less than you think. You need a phone or a computer, a way to get online sometimes, and a little time each day. You do not need to buy a course. You do not need a powerful machine for the first lessons, which are mostly reading, typing and small exercises.

Two things help a lot. First, a notebook where you write what you learned each day. Second, a regular time, even 30 minutes after supper. Small steps done often beat one long night once a month.

Data is a real worry in Tanzania. Video lectures use a lot of data, so plan to watch them on Wi-Fi at a school, library or friend's place. Reading lessons and typing exercises use far less. Our guide on [saving mobile data when studying online](/post/educational/online-learning/save-mobile-data-when-studying-online/) has practical tips. We did not confirm whether any of these courses work fully offline, so do not count on that.

## Option 1: freeCodeCamp, step by step in the browser

freeCodeCamp describes itself as a nonprofit that is supported by donors. On its About page it says that every part of it is free. You build projects step by step in your browser, in a code editor or in its mobile app, and you can do the coding challenges in any order.

It also offers free verified certifications. As checked in November 2026, the About page says each one takes about 300 hours on average, at your own pace. That is a lot of hours, and it is honest to say so. Think of it as months of steady study, not a weekend course.

This option suits you if you like to learn by doing. You read a short idea, then you type code straight away and see if it works.

## Option 2: MDN for web pages

MDN Web Docs, from Mozilla, has a learning path called "Learn web development". It is made for people who start from nothing and want to become comfortable. It begins with "Getting started" lessons about setting up and basic ideas, then moves to core lessons.

The topics are:

- HTML: the structure of a page, links, images, tables and forms.
- CSS: colours, text, boxes and page layout, including pages that fit small phone screens.
- JavaScript: variables, loops, functions and events, which make a page respond to the reader.

MDN also has "Test your skills" exercises and bigger "Challenges" that join several ideas into one project. We saw no price on the page we read, so the lessons carry no paywall there. The page says the content is under a Creative Commons licence. Some partner courses linked from MDN do charge, so read before you pay for anything.

## Option 3: Harvard's CS50x

CS50x is the free online version of a Harvard University course. As checked in November 2026, its page says anyone can take it free through OpenCourseWare, with or without earlier programming. It has eleven weeks of material and then a final project.

The course teaches C, Python, SQL, HTML, CSS and JavaScript. To send in your work for feedback you need a free edX account. Certificates are optional, and the page points to other pages for those, so check them for any cost. You do not need a certificate to learn from the lessons.

CS50x is serious and can be hard. It suits you if you want to understand how computers work, not only how to build a web page. Lecture videos use more data, so plan around Wi-Fi.

## Option 4: Python from python.org

Python is a language many beginners start with. The official site python.org offers downloads for Windows, macOS, Android and iOS, and says all Python releases are open source. We do not name a version here because versions change; download the current one from the page.

The official beginner page points to a short tutorial, the main documentation and beginner books and samples. It calls the tutorial "fairly brief". It also lists material in languages other than English. Be careful to download Python only from python.org. Our post on [installing and removing Windows programs safely](/post/technology-solutions/software/install-and-remove-programs-on-windows-safely/) explains why.

We do not say Python is the best language. The best one for you is the one you will actually practise.

## A simple first-month plan

This is an example plan, not a rule. Change it to fit your days.

1. **Week 1:** Set up. Pick one place (freeCodeCamp or MDN). Do your first lessons on HTML. Write one small page about yourself.
2. **Week 2:** Learn CSS. Change the colours and the layout of your page. Look at it on a phone.
3. **Week 3:** Start JavaScript. Make a button that changes some text.
4. **Week 4:** Build one small thing, such as a page for an imaginary shop. Then decide whether to go deeper into web pages or try Python.

When you get stuck, and you will, that is normal. Read the error message slowly, try one change at a time, then ask a teacher or a friend. Taking a break and coming back often solves it.

## How do you keep going?

Motivation comes and goes. A habit stays. Choose a fixed time, keep the goal small ("one lesson today"), and mark each finished day on a calendar. Learn with a friend if you can, because you can explain things to each other.

Be patient about money too. Learning to code does not promise a job or an income. It is a skill, and what you do with it depends on your effort, your projects and your chances. Treat it as something that can grow slowly.

## Common questions

### Do I need a laptop?

A laptop makes typing code easier. freeCodeCamp says you can learn in its mobile app too, so a phone can be a start. Many learners use both.

### Which language should I learn first?

For web pages, start with HTML, CSS and JavaScript. If you want a general first language, Python is a common choice. Pick one and stay with it for a month before you judge it.

### Is a certificate necessary?

No. You can learn from the lessons without one. If you want a certificate, read the cost and rules on each official page first.

### How long will it take?

It depends on your time. freeCodeCamp says each of its certifications takes about 300 hours on average, and CS50x has eleven weeks of material. You will see small results much sooner.

## What to do next

1. Choose one resource today: freeCodeCamp or MDN are good places to start.
2. Write down a daily time and put it on your phone as a reminder.
3. Finish your first lesson this week and build one tiny page.
4. Plan your Wi-Fi time for any video lessons.

You do not need to be fast. You only need to begin, and then come back tomorrow.
