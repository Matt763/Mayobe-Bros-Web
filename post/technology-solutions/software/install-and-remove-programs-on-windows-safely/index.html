How to Install and Remove Windows Programs Safely

Where to download Windows programs, a short checklist before you install, and how to uninstall in Settings or Control Panel when you are done.

A PC that is slow, full of pop-ups and running strange programs often got that way through careless installs. The good news is that a few habits keep a computer clean, and that removing a program you no longer need takes only a minute.

The short answer

Download programs only from the maker's own website or from the Microsoft Store. Read each installer screen before you click Next. Remove programs you do not use in Settings, or in Control Panel if Settings will not do it. If something strange stays behind, run a full scan with Windows Security.

  • Official sources first: the maker's site or the Microsoft Store.
  • Slow down at installer screens, because extras often hide there.
  • Uninstall what you do not use.
  • Never use cracked or "activated" software. It is illegal and a common way to catch malware.
  • Keep your files backed up before big changes.

Where should I get software?

Microsoft says to download apps from trusted sources such as the Microsoft Store, and to be selective about what you install. For programs that are not in the Store, go to the website of the company that makes the program. Type the address yourself or use a link from a source you trust. Do not use the first advert in a search result without checking the address.

The same is true for drivers, which are the small programs that run parts like a printer or graphics card. Microsoft says to get drivers from the device maker's site and to avoid any other site.

Microsoft Edge uses a tool called Microsoft Defender SmartScreen, which can help block potentially unwanted apps. If it warns you about a file, take the warning seriously. Do not install software from sites that give you "free full version" of paid programs, because that is piracy and often carries malware. If you want a program but cannot pay, look for a free alternative made by an honest maker.

Pop-ups that promise a "free upgrade" or a "driver update" are a common trick. Close them and go to the maker's real site yourself instead.

What should I check before I click Install?

Run through this list each time. It takes one minute.

  1. Do I really need it? Fewer programs means a faster, safer PC.
  2. Is this the maker's own site? Check the address bar. Look for small spelling tricks.
  3. Is the file name what I expected? A "setup" file for a photo viewer should not be huge or strange.
  4. Does Windows or SmartScreen warn me? If yes, stop and look again.
  5. Do I have a back-up? If it is a big program, copy your key files first. Our guide to backing up your computer files shows how.

Then, during the installer, read each screen. Many installers have a "Custom" or "Advanced" choice, and boxes already ticked for extra programs or toolbars. Untick what you did not ask for. Microsoft calls this grey area "potentially unwanted apps": programs that are not clearly malware but that you might not want. Windows can warn you about them and let you decide.

How do I uninstall a program in Settings?

Microsoft's page gives the same steps for Windows 10 and Windows 11, though the words on screen can differ a little. We describe the Windows 11 path, and tell you where Windows 10 differs.

  1. Open Start, then Settings.
  2. Choose Apps, then Installed apps. On Windows 10, the list may be called Apps & features.
  3. Find the program. Select the More icon (three dots) next to it.
  4. Choose Uninstall and follow the prompts.

You can also open Start, select All apps, right-click the program and choose Uninstall.

How do I uninstall in Control Panel?

Microsoft says some programs cannot be removed from Settings, so use Control Panel for those.

  1. Search for Control Panel on the taskbar and open it.
  2. Go to Programs, then Programs and Features.
  3. Right-click the program and choose Uninstall (or Uninstall/Change).
  4. Follow the steps on screen.

Some apps are built into Windows and cannot be removed. Microsoft does not list which ones on that page, so if there is no Uninstall button, that may be why.

What if a program will not uninstall?

This happens, and it is not your fault. Some programs leave a broken uninstaller behind, or are still running when you try to remove them.

First, restart the PC and try again. If you see an error, Microsoft suggests the Program Install and Uninstall Troubleshooter. Microsoft names it on its uninstall help page, so search for it by that name.

If you think unwanted software is still on the PC, Microsoft's advice is:

  1. Open Windows Security and update the security intelligence.
  2. Run a full scan with Microsoft Defender Antivirus.
  3. If the software stays, you can run an offline scan with Microsoft Defender Offline.

Windows 10 reached the end of its support on 14 October 2025, according to Microsoft, and no longer gets free security fixes. If your PC runs it, be extra careful about what you install and consider the move to Windows 11 when you can.

We do not recommend third-party "cleaner" or "uninstaller" tools here. We did not open an official source that backs them, and some such tools are themselves unwanted software.

What should I do about programs that came with the PC?

Some apps are built into Windows, and you cannot remove them. Others were added by the shop or the maker. If you did not choose a program and you do not use it, you may remove it with the same steps. If you are not sure what it does, leave it until you have asked someone you trust, because a few of them keep the PC running.

How do I tell if my PC has unwanted software?

Signs include pop-ups when you are not browsing, a changed home page, new toolbars you never added, and programs in the list that you do not remember installing. Look through your installed apps list once a month. If you see something you did not install and do not know, search its name on the maker's official site or ask a trusted person before you remove or keep it.

Common questions

Is the Microsoft Store safer than a website?

Microsoft recommends it as a trusted source. Not every program is in the Store, though, and for those the maker's own site is the next best place.

Can I reinstall a program I removed?

Yes, in most cases you can download it again from the same official source. Your own files are often kept separately, but check before you uninstall anything that holds work you need.

Is it fine to use a cracked program?

No. It breaks the law, and it is a common route for malware. Use the free tools many makers provide, or save for the real one.

Why is my PC still slow after removing things?

Many things slow a PC, such as low storage or an old machine. Our post on speeding up a slow Windows PC lists more checks.

What to do next

  1. Open your installed apps list today and write down three programs you never use.
  2. Uninstall them, one at a time, using Settings.
  3. Run a full scan in Windows Security.
  4. Next time, read the installer screens and untick what you did not ask for.

A cleaner PC is a small win, and you can have it this evening.
